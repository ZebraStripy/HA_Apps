# Timestamp Logger Home Assistant Add-on

Logs the current timestamp every 60 seconds to the add-on log.

## Install

1. Copy this folder into your Home Assistant add-on repository.
2. In Home Assistant, open **Settings → Add-ons → Add-on Store**.
3. Open the repository menu and add the local/custom repository containing this add-on.
4. Install **Timestamp Logger**.
5. Start it and open **Log** to see a timestamp once per minute.

Example output:

`2026-08-25 20:21:00 BST`
